# VR Control Center

Локальный центр управления VR-ареной OnePlace: подключение Quest, независимые
трансляции, приложения на шлемах и запуск игр на ПК на ПК. Electron, Vue 3,
TypeScript; интерфейс на русском и английском.

## Windows

Установите `VR-Control-Center-<version>-win-x64-setup.exe` из выбранного релиза
либо распакуйте ZIP целиком и запустите `VR Control Center.exe`.
Windows x64 комплект включает ADB, scrcpy, сервер и DLL; отдельно ставить Node.js,
npm или SideQuest не требуется. Источник инструментов — **Автоматически**.

Для первого подключения разрешите USB-отладку в шлеме и нажмите
**Подключить через USB**. ПК и шлем должны быть в общей локальной сети.
Кабель отключайте после подтверждения Wi-Fi-подключения. Для подготовленного
шлема можно вручную добавить `IPv4:порт`.

Пакеты пока без цифровой подписи. Физические устройства, USB-драйвер и настройки
сети проверяются на целевом ПК по [инструкции](docs/operations.md).

## Запуск из исходников

Node.js 24 и npm. Выполняйте команды в каталоге проекта, рядом с `package.json`:

```sh
npm ci
npm run dev
```

На macOS нужны ADB/scrcpy из PATH или custom-пути. На Windows x64 комплект для
разработки подготавливает `npm run tools:prepare:win`. Если install scripts были
отключены, см. [подготовку Electron](docs/development.md).

## Проверки и сборка

```sh
npm run lint
npm test
npm run build
```

`build` включает TypeScript main, Vue renderer и тестов. Тесты находятся в `tests/`,
production-код — в `src/`.

Для Windows x64 на Windows или через GitHub Actions:

```sh
npm run build:win
```

Создаются установщик, полный ZIP, инструкция, контрольные суммы и отчёты проверки
встроенных инструментов. macOS: `npm run build:mac`; комплект ADB/scrcpy туда не
включается. Подробности и порядок публикации — в
[документе о релизах](docs/testing-and-release.md).
