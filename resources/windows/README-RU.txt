VR Control Center — OnePlace, Windows x64

Установка: запустите файл с окончанием -setup.exe.
Без установки: распакуйте ZIP целиком и запустите VR Control Center.exe.
Не переносите один EXE отдельно от остальных файлов распакованного приложения.

ADB, scrcpy, scrcpy-server и необходимые DLL уже включены. SideQuest, Node.js,
npm и отдельная установка ADB/scrcpy для работы приложения не требуются.
В настройках источник инструментов «Автоматически» использует встроенный комплект.
Для старой конфигурации, где выбран PATH, переключите источник на «Автоматически».

Шлем должен находиться в той же локальной сети. На нём должны быть включены
режим разработчика и отладка, а подключение этого ПК — разрешено на шлеме.
При первом запуске игры разрешите необходимые локальные соединения в брандмауэре.

Приложения шлема запускаются из карточки устройства. Франшизные игры и серверы ПК
добавляются в разделе «Командные игры» через существующие ярлыки Windows.
Правильное время можно установить из меню ⋯ карточки подключённого шлема:
«Установить актуальное время». Источник времени — часы этого ПК.

Лицензии и сведения о сторонних инструментах находятся в resources/third-party
и resources/tools/win32-x64/scrcpy/LICENSE.txt. Файл bundle-manifest.json содержит
версии, источник и контрольные суммы встроенных файлов.
