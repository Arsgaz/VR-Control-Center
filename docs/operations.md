# Руководство оператора

## Установка и первый запуск

Для Windows x64 используйте установщик `*-win-x64-setup.exe` или ZIP из выбранного
релиза. ZIP распакуйте целиком и запускайте `VR Control Center.exe` из него.
Один EXE переносить нельзя: ресурсы и инструменты находятся рядом в каталоге сборки.

ADB, scrcpy, сервер scrcpy, DLL и лицензии включены в Windows-пакет. Node.js,
npm и SideQuest для работы не требуются. Пакеты пока без цифровой подписи.
USB-драйвер устройства при необходимости устанавливается отдельно в Windows;
наличие `adb.exe` само по себе не устанавливает драйвер.

Настройки открываются шестерёнкой сбоку. В источниках ADB и scrcpy выберите
**Автоматически**. У старой конфигурации может сохраниться выбор PATH: тогда
переключите оба источника. На macOS используются инструменты из PATH или пути,
указанные в настройках.

## Подключение шлема через USB

1. Включите режим разработчика шлема. Подключите шлем и ПК к общей локальной сети.
2. Подключите шлем USB-кабелем с передачей данных. Наденьте шлем и разрешите отладку
   для этого компьютера.
3. В разделе **Устройства** нажмите **Подключить через USB**. Один шлем выбирается
   автоматически; если их несколько, выберите нужный по модели и серийному номеру.
4. Дождитесь сообщения об успешном Wi-Fi-подключении. После него кабель можно вынуть.

Приложение определяет IP, включает сетевую отладку на порту 5555, подключается по
Wi-Fi и сверяет аппаратный serial. Карточка добавляется автоматически; карточка
с тем же адресом переиспользуется без изменения имени и профиля.

Если разрешение отладки появилось уже после ошибки, подтвердите его и нажмите
**Подключить через USB** ещё раз. Во время настройки кабель не отключайте.
Окно открывается только для выбора из нескольких USB-шлемов; прогресс, ошибки и
успех отображаются в разделе устройств и журнале событий. Если карточка не
сохранилась, кнопка **Повторить сохранение** повторяет сохранение подтверждённого
подключения без повторного `tcpip`.

После перезапуска шлема сетевую отладку может потребоваться включить заново тем же
способом. Включённый TCP/IP не заменяет разрешение отладки и не исправляет проблемы
Wi-Fi. Используйте доверенную сеть арены.

## Уже настроенный шлем и ручное добавление

Если TCP/IP-отладка включена ранее, можно добавить шлем вручную: имя, `IPv4:порт`
и профиль трансляции. Затем нажмите **Подключить** в карточке. Один IP без порта
не принимается. Кнопка подключения не включает `tcpip` на недоступном по сети шлеме.

Каждая карточка управляет своим адресом. Можно подключить несколько шлемов и
одновременно вывести несколько трансляций. Кнопка **Отключить** останавливает
трансляцию этого шлема и приостанавливает его автоподключение до ручного подключения
или перезапуска приложения.

Приложение не ищет новые IP автоматически. Если DHCP сменил адрес, исправьте его
в карточке или повторите USB-настройку. Во втором случае новый адрес создаст новую
карточку; старую удаляют вручную. Для постоянных карточек удобно закрепить адреса
на роутере. Постоянная аппаратная привязка шлемов пока не реализована.

## Трансляция и батарея

**Запустить трансляцию** открывает отдельное окно scrcpy выбранного шлема.
Профиль задаёт размер, FPS, bitrate, кодек, обрезку и звук. Если профиль карточки
не выбран, main использует первый доступный профиль. Снижение размера/FPS может
уменьшить нагрузку; подходящие значения проверяются на игровом ПК.

**Остановить** завершает только эту трансляцию. При потере Wi-Fi она сама заново
не запускается: после восстановления соединения запустите её вручную.
Статус запуска процесса ещё не гарантирует, что видеокадр появился.

Батарея автоматически читается не чаще раза в 30 секунд при видимом окне и
120 секунд в фоне. Возврат из трея запрашивает свежие данные. Для ручного
обновления списка ADB и телеметрии нажмите **Обновить** в разделе устройств:
не нужно ждать двух минут. Значения могут обновиться позже при занятом ADB.

## Игры

### На шлеме

Подключите шлем и откройте **Приложения** в его карточке. Список установленных
запускаемых приложений читается с выбранного устройства. Поиск работает по названию
и package name. Названия и обложки подтягиваются автоматически, пока библиотека
открыта; отдельная кнопка скачивания не нужна.

Неизвестный пакет отображается с техническим именем и стандартной картинкой.
Это не мешает запуску. Для первой загрузки обложек нужен интернет на ПК, для запуска
установленной игры через ADB он не требуется. Интернет самой игре может быть нужен
независимо от приложения. Не все vendor-specific приложения разрешают обычный
Android-запуск: отказ отображается как ошибка.

### На ПК — «Игры на ПК»

Нажмите **Добавить игру**, задайте имя, при необходимости заметку и выберите
существующий ярлык игры или сервера. Поддерживаемые файлы Windows:
`.lnk`, `.url`, `.exe`, `.bat`, `.cmd`; macOS: `.app`, `.webloc`, `.command`.
Параметры запуска и рабочую папку настройте в самом ярлыке.

По умолчанию карточка показывает системную иконку выбранного ярлыка. В редакторе
есть **Загрузить PNG…** с предпросмотром: файл до 2 МБ, стороны до 4096 пикселей.
Копия сохраняется в данных приложения, поэтому оригинал после импорта можно
перенести. Нажмите **Сохранить**, чтобы применить выбор. **Использовать иконку ярлыка**
убирает собственную картинку. Без доступной иконки остаётся стандартная монограмма.

Карточка предлагает **Запустить** и редактирование. Удаление записи не удаляет файл.
Если ярлык переместили, обновите путь. Сообщение об успехе означает, что ОС приняла
команду: готовность игрового сервера нужно проверить в его собственном окне.
Выход из VR Control Center не закрывает такие игры/серверы.

### Установленные игры Steam с поддержкой VR

При открытии **Игры на ПК** приложение ищет Steam и проверяет установленные игры
во всех доступных библиотеках. Можно нажать **Обновить SteamVR** вручную.
Если Steam не найден, используйте **Папка Steam…** и выберите каталог Steam с
подпапкой `steamapps`; выбор сохраняется между запусками.

Добавляются именно игры, у которых магазин Steam указывает VR Support, VR Only
или VR Supported. Простая поддержка контроллера не считается VR. SteamVR как
служебное приложение отдельной игровой карточкой не импортируется.

Для первой проверки поддержки VR и загрузки обложек нужен интернет на ПК.
Проверенные данные кэшируются на 7 дней и используются при отсутствии сети.
Проверки идут максимум в два потока с ограниченным временем сетевого этапа.
Если часть игр не проверилась, повторите обновление: отсутствие ответа не считается
отсутствием поддержки VR. При недоступном/регионально закрытом магазине некоторые
игры могут остаться непроверенными; их можно добавить обычным ярлыком вручную.

Повторный импорт не дублирует AppID и не переписывает ваши названия, заметки,
собственные PNG и галочку SteamVR. Удалённые из Steam игры автоматически из
карточек не удаляются, но их запуск проверяет установленность. Удалённая вручную
импортированная карточка появится снова при синхронизации, пока игра установлена.

### Сначала SteamVR, потом игра

В редакторе любого ярлыка есть **Требуется SteamVR**. С этой галочкой запуск на
Windows x64 сначала проверяет подключение к OpenVR runtime. Если оно уже доступно,
второй запуск SteamVR не запрашивается. Иначе приложение запускает SteamVR через
Steam и ждёт до 45 секунд подтверждения подключения к runtime, затем открывает
ярлык или Steam-игру. Пока идёт подготовка, карточка показывает соответствующий статус.

При ошибке/таймауте игра не открывается: проверьте окно SteamVR, подключение шлема
и повторите запуск. Steam и SteamVR должны быть установлены; приложение их не
скачивает и не подключает PC VR вместо Air Link/Steam Link/Virtual Desktop.
Успешная проверка runtime не подтверждает tracking или наличие первого кадра.

Для импортированных VR-игр галочка включена по умолчанию и может быть снята.
Запуск самой Steam-игры идёт через Steam по AppID с его настройками запуска:
для игр с плоским и VR-режимом проверьте выбранный режим в клиенте Steam.
Галочка запускает SteamVR, но не преобразует обычную игру в VR. Если игра использует
другой OpenXR runtime и SteamVR ей не нужен, галочку снимите.

## Исправление времени

В меню **⋯** подключённой карточки выберите **Установить актуальное время**.
Источник — часы этого ПК; сначала проверьте их. Интернет на шлеме и сайты с epoch
для этого действия не нужны. Часовой пояс не меняется.

Успех показывается после проверки часов шлема. Прошивка может запретить команду.
Ошибка проверки означает, что результат подтвердить не удалось, даже если сама
команда изменения времени уже выполнилась.

## Фоновая работа и выход

В настройках можно выбрать сворачивание в трей при закрытии окна. Трей предлагает
открыть приложение или выйти. Просто скрытое окно сохраняет трансляции и соединения,
поэтому потребление ресурсов не становится нулевым. Опрос батареи и foreground
становится реже. **Выход** прекращает управление и запрашивает остановку scrcpy.

## Диагностика

| Симптом                         | Что проверить                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| USB-кнопка недоступна           | Доступность ADB и источник инструментов в настройках                                  |
| USB не обнаружен                | Кабель с данными, порт, режим разработчика, драйвер Windows                           |
| Нет авторизации                 | Разрешение USB-отладки внутри шлема для этого ПК                                      |
| USB есть, Wi-Fi не подключается | Одна сеть, адрес `wlan0`, изоляция клиентов/брандмауэр, повтор с подключённым кабелем |
| Шлем был доступен, теперь нет   | Питание/Wi-Fi, смена IP, включён ли TCP/IP после перезапуска                          |
| Соединение есть, картинки нет   | Доступность scrcpy, профиль, его окно и технический лог                               |
| Обложки отсутствуют             | Интернет ПК и наличие пакета в публичных источниках; запуск доступен без картинки     |
| Сервер ПК не готов              | Реальный ярлык и окно сервера; статус готовности приложение не отслеживает            |

В деталях карточки видны состояния и время последнего обновления. В настройках
можно открыть каталог технических логов. Перед передачей лога проверьте его на
локальные адреса, пути и другие данные. Очистка старых логов не удаляет активный.

Для переноса конфигурации закройте приложение, сохраните резервную копию
`config.json` из показанного каталога данных и переносите её целиком. Для сохранения собственных иконок также скопируйте
каталог `team-game-icons` рядом с конфигурацией. Пути ярлыков
на другом ПК могут отличаться. Редактирование файла при работающем приложении не
подхватывается и может быть перезаписано следующим сохранением.
