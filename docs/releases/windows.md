# OnePlace VR Control Center v0.3.0 — Windows x64

- Управление несколькими Quest, независимые подключения и трансляции.
- Кнопка подключения через USB: настройка Wi-Fi и автоматическое добавление карточки.
- Игровая библиотека шлема с автоматическими названиями и обложками.
- «Игры на ПК»: ярлыки, свои PNG и автоматические системные иконки.
- Импорт установленных Steam-игр с официальной VR-категорией и обложками.
- Галочка «Требуется SteamVR»: проверка/подготовка runtime перед запуском игры (Windows x64).
- Установка и проверка времени выбранного шлема по часам ПК.
- Оформление OnePlace, системный трей и отдельная кнопка настроек.
- Обновлённые шрифты, иконки и компоновка библиотеки; стандартное меню Electron в Windows убрано.
- Защита от запоздалых ответов ADB и гонок при переключении устройств.
- Более редкая телеметрия в фоне и ограниченный оперативный кэш обложек.

Включены scrcpy 5.0.1, ADB 37.0.1, scrcpy-server и весь официальный набор DLL.
Отдельная установка ADB, scrcpy, SideQuest и Node.js не нужна.

**Файлы:** `*-setup.exe` — установщик; `*-win-x64.zip` — полная сборка без
установки (распаковать целиком); `SHA256SUMS.txt` — контрольные суммы;
`README-Windows.txt` — инструкция. JSON-отчёты содержат результаты проверки
комплекта и запуска встроенных инструментов в Windows без системного PATH.

Установщик без цифровой подписи. Фактическое подключение, трансляция и изменение
времени требуют проверки на физическом Quest. Успех запуска ярлыка означает
принятие команды Windows, а не готовность сервера франшизы.
