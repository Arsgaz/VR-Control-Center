# OnePlace VR Control Center v0.3.1 — Windows x64

Исправления интерфейса и подключения после v0.3.0:

- Кнопки карточки шлема находятся в одном ряду и не смещаются при подключении
  или запуске трансляции. Подписи действий стали компактнее.
- «Подключить через USB» сразу настраивает единственный шлем. Окно выбора
  появляется только при нескольких USB-устройствах. Прогресс, ошибки и результат
  показываются на странице и в журнале событий.
- Повтор сохранения карточки не перезапускает уже подтверждённое подключение.
  Состояние USB-операции сохраняется при переключении разделов.
- Единый минималистичный шлем OnePlace для значка приложения, ярлыков и трея.
  Windows-трей адаптируется к светлой и тёмной теме панели задач.
- В навигации используется шлем из логотипа; убраны общие подписи под заголовками.
- Исправлены отступы действий в настройках журналов. Кнопки больше не прилипают
  к панели путей файлов.
- Единые PNG/ICO/ICNS и корректное имя macOS dev-контейнера. Изменение отображаемого
  имени сохраняет существующие пути конфигурации и логов.

Обновление не требует удаления конфигурации или повторного добавления игр.

Включены scrcpy 5.0.1, ADB 37.0.1, scrcpy-server и весь официальный набор DLL.
Отдельная установка ADB, scrcpy, SideQuest и Node.js не нужна.

**Файлы:** `*-setup.exe` — установщик; `*-win-x64.zip` — полная сборка без
установки (распаковать целиком); `SHA256SUMS.txt` — контрольные суммы;
`README-Windows.txt` — инструкция. JSON-отчёты содержат результаты проверки
комплекта и запуска встроенных инструментов в Windows без системного PATH.

Установщик без цифровой подписи. Фактическое подключение, трансляция и изменение
времени требуют проверки на физическом Quest. Успех запуска ярлыка означает
принятие команды Windows, а не готовность сервера франшизы.
